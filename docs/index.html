Claude Code skill · ai-privacy-audit

Vos données clients partent-elles vers une IA ?

Un skill Claude qui audite une codebase : données personnelles envoyées aux API LLM, prompt injection, RAG sans contrôle d'accès, prompts dans les logs, clés exposées. Ci-dessous, le replay de l'audit réel sur une app de test contenant 8 failles volontaires.

1 · Cartographier

Repère chaque appel à un LLM, embedding ou vector store (OpenAI, Anthropic, Mistral, Gemini, Pinecone, Qdrant…).

2 · Tracer le flux

Remonte d'où viennent les données du prompt. Constante = rien. user.email = constat.

3 · Calibrer

Gravité selon l'impact réel : un agent avec SQL + entrée libre est critique, un chatbot sans outils ne l'est pas.

4 · Rapporter

Constats fichier:ligne vérifiés, scénario, correctif. Aucun secret recopié, aucun code modifié.
